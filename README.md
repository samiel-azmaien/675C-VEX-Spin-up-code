A historical snapshot of team 675C's VEX V5 code for the *Spin Up* season, built with PROS and EZ-Template.

## Robot capabilities

- Six-motor drivetrain with PID-based movement
- Match and skills autonomous routines
- Autonomous routine selection
- Flywheel, intake, roller, and indexer control
- Pneumatic expansion and mechanism control
- Driver-control mappings for competition operation

## Repository format

The original project is preserved in [`norcal trash (1).zip`](./norcal%20trash%20%281%29.zip). The archive contains the PROS project, authored source, framework dependencies, editor caches, and historical build output.

GitHub cannot render or index source code stored inside a zip file. A future cleanup should extract the authored `src/` and `include/` directories, remove generated artifacts, and pin dependency versions in a conventional PROS project layout.

## Stack

- VEX V5
- C++
- PROS 3.7.3
- EZ-Template 2.1.2

## Build status

This snapshot has not been verified against a current PROS toolchain. It contains historical calibration values and known incomplete references, so review the code and robot configuration before attempting to build or deploy it.
